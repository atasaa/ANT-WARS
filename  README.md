# ANT WARS

A massive open-world 3D ant survival and multiplayer game.

## Game Concept
You begin as a lone soldier ant with no colony. Explore the world, find a mate, establish a colony, and expand your territory.

## Main Features
- First-person ant gameplay
- Soldier ant and queen characters
- Colony building and management
- Huge open world
- Online and offline gameplay
- Cooperative and competitive multiplayer
- Wildlife and insect ecosystems
- Realistic 3D graphics
- Adjustable graphics settings for mobile devices

## Technology
- Three.js
- React
- GitHub
- Vercel
- Supabase
- Dedicated multiplayer server
